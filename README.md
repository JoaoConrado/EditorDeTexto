# Editor de Texto

Este projeto é um editor de texto simples, desenvolvido em **C#**. Foi criado para testar e aprimorar conhecimentos em desenvolvimento de aplicações de desktop, manipulação de arquivos e interfaces gráficas de usuário (GUI).

## 🚀 Funcionalidades Principais

* **Edição de Texto:** Permite criar, abrir, editar e salvar arquivos de texto.
* **Manipulação de Arquivos:** Lógica para ler e escrever dados em arquivos, garantindo a persistência do conteúdo.
* **Interface Gráfica:** Uma interface de usuário intuitiva para interagir com o editor.
* **Menus e Atalhos:** Implementação de menus para funções básicas como "Novo", "Abrir" e "Salvar".

## 🧠 Estrutura do Projeto

O projeto segue a estrutura padrão de um aplicativo C# no Visual Studio, com os seguintes componentes principais:

* `Editor de texto.sln`: O arquivo de solução do Visual Studio que organiza o projeto e seus componentes.
* `Editor de texto/`: A pasta principal do projeto que contém o código-fonte (provavelmente `Program.cs`, `Form1.cs`, etc.).
* `.gitignore` e `.gitattributes`: Arquivos de configuração do Git para gerenciar versões.

## 🛠️ Como Executar

Para compilar e executar o projeto, você precisará do **.NET SDK** e de um ambiente de desenvolvimento como o **Visual Studio**.

1.  **Pré-requisitos:** Certifique-se de ter o [.NET SDK](https://dotnet.microsoft.com/download) instalado.
2.  **Clonar o Repositório:**
    ```bash
    git clone [https://github.com/JoaoConrado/EditorDeTexto.git](https://github.com/JoaoConrado/EditorDeTexto.git)
    cd EditorDeTexto
    ```
3.  **Abrir no Visual Studio:** Abra o arquivo de solução (`Editor de texto.sln`) no Visual Studio.
4.  **Compilar e Rodar:** Pressione F5 ou clique em "Start" para executar a aplicação.
